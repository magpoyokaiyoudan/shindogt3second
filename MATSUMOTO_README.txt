SHINDO GT3 second ― 松本市街地(新コース)

【遊び方】
 ホーム → START → コース選択の ◀▶ で「松本市街地」→「出発地点を選ぶ」→ 地図の道路をタップ(または「松本駅前から出発」)。
 周回レースではなく、信号や一般車のある実在の街を自由に走るコースです。オンライン対戦・タイムアタックのコース選択には出ません。

【使用データ(実データ・加工して組み込み)】
 ・建物: 国土交通省 PLATEAU 3D都市モデル 松本市(2020年度) CityGML v4
   - LOD2(範囲内の全4,106棟): 壁・屋根の全ポリゴンと、データに入っている実写テクスチャを縮小せずそのまま使用(mz/h*.jpg)
 ・道路網: OpenStreetMap(© OpenStreetMap contributors, ODbL) ― 交差点・一方通行・車線数・信号機の位置・横断歩道・バス停
 ・道路幅: PLATEAU 道路モデル(tran LOD1)の道路区域から実測
 ・標高: 国土地理院 基盤地図情報 数値標高モデル 5mメッシュ(DEM5A)

【ファイル】
 index.html … ゲーム本体(松本の道路・建物形状・地形データを内蔵)
 mz/h{区画}_{n}.jpg … 建物の実写テクスチャ(元の解像度)。mz/l… は遠景用の1/4版
 ※ 再現範囲: 西=松本駅のすぐ西 / 東=市街地東側の幹線 / 北=松本城の北 / 南=駅の南(約1.1km×1.3km、建物4,106棟・道路約32km)。
 ※ 建物テクスチャは縮小していません(品質90で再圧縮)。元データの壁の細かさは1mあたり約6画素です。
 ※ mz フォルダは index.html と同じ場所に置いてください(GitHub Pages などのWebサーバー上で動作。
   iPhoneのファイルアプリから直接開く場合は、ブラウザの制限でテクスチャを読めないことがあります)
